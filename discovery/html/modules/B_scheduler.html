B · V1 Scheduler Per-step token-budget allocation, chunked prefill, preemption, encoder-input scheduling.

Path: vllm/v1/core/sched/
Key files (verified): scheduler.py (2,295 LoC), async_scheduler.py, interface.py (SchedulerInterface, PauseState), output.py (SchedulerOutput, NewRequestData, CachedRequestData, GrammarOutput), request_queue.py (RequestQueue, SchedulingPolicy, create_request_queue), utils.py (check_stop, remove_all).

Owns per-step token-budget allocation across running + waiting requests; handles chunked prefill, preemption (PRIORITY-policy max((priority, arrival_time)) victim selection or LIFO under FCFS), encoder-input scheduling for VLMs, spec-decode token alignment, KV-connector hooks (P/D disaggregation, EC connector), and structured-output flag propagation.

criticality: high target #2 target #10

Scheduler.schedule — main per-step admission & budgeting risk: high

vllm/v1/core/sched/scheduler.py :: Scheduler.schedule (line 352)

The heuristic that selects which waiting request to admit next, the chunked-prefill chunk-sizing rule (long_prefill_token_threshold interaction with token_budget), the preemption victim selection, and the skipped_waiting re-queue logic (linked in issue #27441).

What to evolve
A small Python policy function with restricted API access — only Request.priority, arrival_time, num_prompt_tokens, num_computed_tokens, queue lengths, and kv_cache_utilization exposed.
Evaluator
benchmarks/benchmark_serving.py driving vllm serve against ShareGPT, Mooncake-Conversation, BurstGPT, and a synthetic mixed-prefill-decode trace.
Metric
TTFT p99, TPOT p99, completed-request goodput under SLO.
Fitness
Weighted sum of (TTFT p99 violation rate, TPOT p99 violation rate, throughput).
Expected gain
Sarathi-Serve and Llumnix suggest 1.5–3× goodput from better scheduling; AlphaEvolve specifically reports a discovered datacenter scheduler that recovered 0.7% of Google's compute.
Safety
Must run a fairness regression harness (cf. VTC, Locality-aware Fair Scheduling) — easy to overfit to throughput at the cost of starvation.

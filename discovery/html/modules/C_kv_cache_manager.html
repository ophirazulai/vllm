Evolve Locations

Block-hash strategy risk: medium-high

vllm/v1/core/kv_cache_utils.py

Block-hash function chain (sha256 vs Python hash, mixing of multimodal extra keys, parent-hash chaining order). The caching_hash_fn choice in KVCacheManager.__init__ is already a knob.

What to evolve
Hash function selection + parent-hash chaining order + multimodal-key mixing.
Evaluator
Synthetic workload mixing system prompts, few-shot prefixes, and multi-turn chats with controllable hit rates (0%, 30%, 70%, 95%).
Metric
Maximize cache_hit_rate × throughput, subject to "no false positives" — block-hash collisions must produce identical token sequences.
Correctness oracle
Collision tests on a 1B-token corpus.
Risk
Medium-high — correctness bugs corrupt outputs.
